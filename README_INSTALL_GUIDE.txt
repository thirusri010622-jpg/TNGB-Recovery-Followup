TNGB Recovery & Daily Follow-up Android App
===========================================

Download and run
----------------
- Download the repository as a ZIP using the green Code button on GitHub, then choose Download ZIP.
- Extract the ZIP and open index.html in a modern browser. Data is stored on that device in browser local storage.
- For offline/PWA installation, host the extracted files over HTTPS (or localhost), open the site in Chrome, then choose Install app / Add to Home Screen. The service worker caches the app shell for offline use.

The app includes sample CIFs, NPA and deposit tabs, search, CIF/account editing, adding new records and loans, follow-up entry, local persistence, and an installable web-app manifest. This is a browser-based local-storage app; records are not synced between devices or backed up automatically. Export or back up data before clearing browser storage.
